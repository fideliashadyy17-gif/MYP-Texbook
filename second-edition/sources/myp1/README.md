# MYP 1 Student Coursebook — second edition sources

This directory contains editable sources for the **MYP 1 second edition only**. First-edition PDFs in the repository root are preserved untouched as archive/source material.

## Current deliverable

- **Chapter 1 revision proof:** `../../exports/myp1/MYP1-Chapter-01-Revision-Proof.pdf`
- **Status:** Chapter 1 only. This is a revision proof, not the complete MYP 1 coursebook.
- **Scope source:** first-edition MYP 1 embedded course map (p. 13), Chapter 1 unit planner (p. 19), table of contents, and Chapter 1 text/answers (pp. 18–34; answers pp. 216–218). No standalone MYP 1 curriculum overview/unit documents were present in the repository.

## Build and QA

Requires Node.js ≥ 22 and Python 3 with PyMuPDF/Pillow for post-export QA.

```bash
cd second-edition/sources/myp1/build
npm ci
npm run build      # generates diagrams, HTML and answer pages
npm run check      # Paged.js layout QA in headless Chromium
npm run export     # writes ../../exports/myp1/MYP1-Chapter-01-Revision-Proof.pdf
npm run preview    # local/static preview server on PORT (default 4173)

# Post-export PDF QA (from repository root or build directory)
PYTHONPATH=/path/to/pymupdf python qa_pdf.py 1
python qa_math.py
```

### Sandbox Chromium note

`@sparticuz/chromium` needs its bundled Amazon Linux libraries in this Debian sandbox. The helper sets `AWS_EXECUTION_ENV=nodejs22.x` before import so the libraries are extracted. If a stale `/tmp/chromium` prevents library extraction, remove it and retry. Do not rely on Playwright browser CDN downloads in this environment.

## Editorial and QA principles

- Questions and answers render from the same JSON.
- Mathematical QA recomputes numeric results independently rather than trusting stored answer strings.
- Layout QA checks expected page count, split/missing pages, overflow, raw placeholders/LaTeX and KaTeX errors.
- PDF QA checks page count, embedded fonts, question/answer pairing and renders pages for visual inspection.
- Classroom datasets are explicitly labelled simulated. Real data would require provenance.
- MYP assessment uses **Criterion**, not “Category”. ATL statements use the required wording: “In order for a student to… students must…”.

## Known limitations

- Chapter 1 is a revision proof. Chapters 2–10 are not yet rewritten.
- The PDF is A4 and suitable for proofing/print review; final commercial print production would still need any required bleed/crop marks and printer-specific colour settings.
- The repository did not contain a separate school curriculum overview, so scope is anchored to the verified first-edition embedded planning material.
