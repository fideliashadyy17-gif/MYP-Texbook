Chapter 6 · Mathematical development

6.1 Patterns, rules and sequences

Big idea

Describe how a pattern grows, then connect the picture to a rule for any position.

A sequence has terms in positions 1, 2, 3, …. A term-to-term rule says how to get the next term. A position-to-term rule uses the position n to find a term directly.

For 4, 7, 10, 13, …, add 3 each time. The nth term is 3n + 1 because position 1 gives 4. A rule must match every given term, not only the first.

{{figure:match_chain-6|Each new square shares a side: 4, 7, 10 matches. The rule is 3n + 1.}}
Worked example · A growing matchstick chain

One square uses 4 matches; each extra square shares one side and adds 3.

  1. n squares use 4 + 3(n−1) matches.
  2. Simplify to 3n + 1.
  3. For 10 squares: 31 matches.
3n + 1; 31 matches for 10 squares.

6.2 Expressions and substitution

Big idea

A letter stands for a number. Replace it carefully and follow the order of operations.

An expression such as 3n + 5 combines numbers, letters and operations. It has no equals sign. A term is a part added or subtracted; a coefficient multiplies a letter.

To evaluate, substitute the value and use brackets where needed. If n=4, 3n+5 = 3×4+5 = 17. If x=−2, x² = 4 but −x² = −4.

Worked example · Evaluate 2a + 3b

Let a=5 and b=2.

  1. 2×5 + 3×2.
  2. 10 + 6.
16.

6.3 Simplifying and expanding expressions

Big idea

Combine only like terms; use the distributive law to remove brackets.

Like terms have the same letter part. 3x + 5x = 8x, but 3x + 5 cannot be combined into one term. Rearranging terms does not change their value.

Expanding uses a(b+c)=ab+ac. For 3(2x+4), multiply every term inside: 6x+12. Factorising reverses this: 6x+12 = 3(2x+4).

Worked example · Simplify 4x + 3 + 2x − 5

Group like terms.

  1. 4x+2x = 6x.
  2. 3−5 = −2.
6x − 2.

Chapter 6 · Mathematical development

6.4 Equations, formulas and checking solutions

Big idea

An equation states equality. Keep both sides balanced, then substitute the solution to check.

To solve, undo operations in reverse order. For 3n+5=20, subtract 5 from both sides, then divide by 3: n=5. Whatever you do to one side, do to the other.

A formula connects quantities, such as C=3+2d. To find d when C=19, solve 19=3+2d. A solution should satisfy the original equation and make sense in context.

{{figure:balance-6|Subtract 5 from both sides, then divide both sides by 3: n = 5.}}
Worked example · Solve 4n + 4 = 44

Undo addition, then multiplication.

  1. 4n = 40.
  2. n = 10.
  3. Check: 4×10+4 = 44.
n=10.
