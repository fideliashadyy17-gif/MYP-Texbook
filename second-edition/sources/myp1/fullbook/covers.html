About this book

Ten chapters, each opening with a task rather than a rule. You investigate, notice a pattern, state a mathematical conclusion, and only then meet the formal explanation — with worked examples that model a complete solution and 722 practice items separated into Criterion A, B, C and D practice so you can see which skill each task trains.

Every chapter closes with a Service as Action opportunity, a Community Project connection and a Personal Project extension for MYP 5. The back of the book carries complete student-facing answers with reasoning, a formula bank, a glossary and references.
