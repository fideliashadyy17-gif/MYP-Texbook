# 03 · Chapter and subtopic audits

The chapter/subtopic audit is split by level so that each book can be reviewed independently:

- [MYP1 audit](chapter-audits/myp1-audit.md)
- [MYP2 audit](chapter-audits/myp2-audit.md)

Each level file records chapter pages, framework branch, opener concept/context, inquiry, ATL focus, printed planner/assessment strands, keep/improve/issues/decision, sample QA anchors, numbered subtopics and located learning features.

Supporting registers:
- [Chapter register](evidence/chapter-register.csv)
- [Subtopic register](evidence/subtopic-register.csv)
- [Learning-feature register](evidence/learning-feature-register.csv)

Boundary: the registers are structural and editorial. Mathematical QA is sampled at chapter/capstone level; full exercise/answer/diagram/rubric verification remains a release gate.
